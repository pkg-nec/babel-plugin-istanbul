# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of
@pkg-nec/babel-plugin-istanbul. Users of older versions should upgrade before
reporting an issue.

## Reporting a Vulnerability

Please do not report suspected vulnerabilities in a public issue. Instead,
open a private GitHub security advisory at
https://github.com/pkg-nec/babel-plugin-istanbul/security/advisories/new.

Include the affected version, a minimal reproduction, impact, and any proposed
mitigation. The maintainer will acknowledge the report, assess its impact,
coordinate a fix, and disclose it after a patched release is available.
